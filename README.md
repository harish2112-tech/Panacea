## 🎯 Overview

**PANACEA** is a comprehensive pandemic response toolkit designed to help individuals and communities navigate health crises with confidence. The app provides a unified platform for healthcare access, mental health support, verified information, and community connection.

### Brand Identity

| Element | Value |
|---------|-------|
| **Primary Colors** | Calm Blue (#2E86C1), Soft Green (#27AE60) |
| **Typography** | Inter (Sans-serif) |
| **Logo Concept** | Shield + Heartbeat + Community |

## 🚨 Problem Statement

Pandemics create unprecedented challenges:

| Challenge | Impact |
|-----------|--------|
| **Information Overload** | Misinformation spreads faster than the virus, causing confusion and panic |
| **Healthcare Access** | Finding hospitals, testing centers, and telemedicine becomes overwhelming |
| **Mental Health Crisis** | Anxiety, isolation, and burnout affect millions |
| **Social Isolation** | Communities disconnect when support is needed most |

---

## 💡 Solution

PANACEA addresses these challenges through **four core pillars**:

### 🏥 Healthcare Resources
- **Nearby Healthcare Finder** - Locate hospitals, clinics, testing centers
- **Telemedicine Access** - One-tap connection to doctors
- **Symptom Checker** - Risk assessment questionnaire
- **Vaccination Scheduler** - Book appointments with reminders
- **Health Tracker** - Daily symptom and vitals log

### 🧠 Mental Health Support
- **Guided Meditation** - 5-15 minute audio sessions
- **Mood Tracker** - Daily emotional check-ins
- **Breathing Exercises** - Interactive guided breathing
- **Professional Support** - Therapist directory & helplines
- **Self-Care Activities** - Journaling, affirmations, calming music

### 📊 Information Hub
- **Real-Time Updates** - Case numbers and trends
- **Verified Sources Only** - WHO, CDC, government data
- **Myth vs Fact** - Combat misinformation
- **Localized Alerts** - Region-specific advisories

### 🤝 Community Connection
- **Help Exchange Board** - Request or offer assistance
- **Neighborhood Groups** - Local support networks
- **Volunteer Coordination** - Match helpers with needs
- **Safety Reporting** - Report emergencies or misinformation

## ⚡ Features

| Feature | Description |
|---------|-------------|
| **Symptom Checker** | 5-question assessment with risk level (Low/Medium/High) |

- 🔤 **Font Size Toggle** - Three size levels

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Edge, Safari)
- No server or build tools required

### Running Locally

1. **Clone or download** the project folder
2. **Open** `index.html` in your browser
3. That's it! The app runs entirely client-side

### File Structure

```
panacea/
├── index.html           # Home Dashboard
```

PANACEA is designed to be accessible to everyone:

| **Simple Navigation** | Critical info in ≤2 taps |
